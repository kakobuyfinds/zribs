Before ordering through SuperBuy

  1. Find the original listing. Open the item on HipoBuyFind and locate its seller URL if available. Paste the seller URL into SuperBuy and check whether that listing can be ordered.
  2. Confirm the variant. Record the color, size and measurements for the selected variant. Compare the seller’s size chart with a garment that already fits.
  3. Review warehouse QC. If warehouse photos are available, compare the received item's size tag, color, stitching and visible condition with your order. Check the return terms before approving shipment.
  4. Estimate the delivered total. Add the item cost, domestic delivery, applicable service fees, international freight and any taxes or duties. Check whether the shipping line bills by actual or volumetric weight.

Frequently asked questions

What is a SuperBuy spreadsheet?

It is a list of products and seller links that shoppers can use to compare listings before checking whether their buying agent can order them.

Are the prices shown shipping-inclusive?

The table shows HipoBuyFind listing prices in CNY. Check the current item price and shipping charges before paying.

Where do the buttons go?

Both buttons open the HipoBuyFind homepage, where you can browse the catalog and look up listings.
